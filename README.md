# Braz Motos — Landing Page

Landing page responsiva e de alta conversão para a oficina mecânica e loja **Braz Motos** em Maringá - PR.

## Estrutura do Projeto

- `index.html` — Estrutura semântica em HTML5
- `css/style.css` — Estilos modernos com suporte a Modo Escuro e Modo Claro
- `js/script.js` — Alternância de tema, menu mobile, status de funcionamento e animações
- `assets/logo-braz-motos.jpg` — Logotipo oficial da Braz Motos
